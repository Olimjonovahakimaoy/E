## Vercel'da coinlar boshqa qurilmada ham turishi uchun
Vercel loyihasi → Storage → Upstash Redis (Marketplace) → Connect.
Env o'zgaruvchilar avtomatik qo'shiladi (KV_REST_API_URL, KV_REST_API_TOKEN). Redeploy qiling.
Redis ulanmasa ham sayt ishlaydi, faqat ma'lumot bitta qurilmada qoladi.
